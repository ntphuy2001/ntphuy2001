## Featured work

### SenPet · pet social network

`Go` `Flutter` `React` `PostGIS` `WebRTC` `Redis Streams`

8 Go microservices behind one API gateway, a Flutter app and 2 React portals, all on **one small VPS**.

- **Pet Radar:** PostGIS proximity search that shows only online owners and respects each user's privacy setting.
- **Calls:** real-time chat over WebSocket, plus **self-hosted WebRTC voice and video** with coturn (no Agora or Twilio fees).
- **Reliability:** transactional outbox on Redis Streams, idempotent consumers, asynq background jobs.
- **Clinics:** drag-and-drop vet scheduling with role-based access per location.

### Dynamic ERP · AI-agent-driven engineering

`Go` `PostgreSQL JSONB` `React 19` `Python` `MCP` `Langfuse`

Metadata-driven multi-tenant ERP, used as a testbed for building production software with AI coding agents.

- **Workflow:** planner, implementer and independent auditor agents. No agent reviews its own work.
- **Risk classifier:** sets each task's review level from its actual diff.
- **Orchestrator CLI (Python):** dependency-aware queue, file locking, checkpointed logs, AI provider failover.

### Real-time quiz platform

`Laravel Reverb` `WebSocket` `React` `Redis`

Team Leader on a live quiz played by **150 people at once**. Owned architecture, task breakdown and code review.
